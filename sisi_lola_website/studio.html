Production Pipeline

From whispered Yoruba
to finished episode

Five stages, fully reproducible from the BAMG-Studio repository. No surprise costs. No external bottleneck. Sisi Lola sounds like Sisi Lola — every time.

Stage 01

Sourcing

8 native Nigerian female speakers selected from the FLEURS Yoruba dataset. Each sample 24-25 seconds, hand-picked for clarity and prosody.

FLEURS · HF Datasets
Stage 02

Reference Build

Top 3 speakers merged into a 75-second reference clip, loudness-normalised to -18 LUFS, resampled to 22 kHz mono. The voice DNA of Sisi Lola.

FFmpeg · loudnorm
Stage 03

Writing

Scripts hand-written in Yorunglish — 60% Pidgin, 30% Yoruba, 10% English — with full diacritical marks so the voice clone gets the tones right.

Yorùbá · Naija Pidgin
Stage 04

Voice Clone

XTTS-v2 zero-shot clones the native reference. Scripts are chunked into 140-char segments for fast inference. Output is concatenated to one clean audio track.

Coqui XTTS-v2
Stage 05

Render

Ken-Burns motion across persistent Sisi Lola keyframes, crossfaded mid-episode, synced to the native audio. 1080p H.264 ready for the web.

FFmpeg · zoompan · xfade

The Repository

Built once. Reproducible forever.

Every script, every reference clip, every line of synthesis code is committed to BAMG-Studio/sisi-lola-project on GitHub. If something needs to change, change the script, run the pipeline, and Sisi Lola records again in her own voice.
